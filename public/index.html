Contributing

To try a new idea or contribute to an existing repo:

  1. Open a repo or send a PR.

    Create a new repo in the GitHub organization or send a contribution to an existing one.

  2. Prepare your static files.

    Put your HTML, CSS and JS files in the public folder; a build step is optional.

  3. Publish.

    See the Contributing Guide for step-by-step setup. The site deploys automatically after merge.

About

What is it?

Collective Bucket offers a starter template so you don't have to rebuild the infrastructure every time you try a new idea. Hosting, authentication and UI needs live in one place; each app lives in its own repo.

For a developer, this platform is like a pocket knife: with AI help, an idea can come to life in minutes. That convenience shouldn't belong to one person only, so the platform is open to every developer and is named Collective Bucket.

Goal

cost
Start on the free tier; no credit card required.
license
MIT — every repo is open source.
scope
Static hosting, shared sign-in and shared UI components.

Technical choices

  • One Firebase project, a separate hosting site per repo
  • Static files and automatic deploys
  • Firestore and security rules for apps that need data
  • Central session: auth.collectivebucket.com

Design choices

  • Light theme, pastel mint accent
  • Inter and JetBrains Mono typography
  • Shared shell components
